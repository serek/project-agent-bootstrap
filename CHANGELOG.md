# Changelog

This changelog covers the project-agent-bootstrap package. Keep changes under
Unreleased until the local checks pass and hosted CI or equivalent host-side
evidence is available. Then publish a dated release entry and matching stable
version tag. Include behavior changes, breaking changes, security fixes, and
migration notes where applicable; routine internal edits need no entry.

Use semantic versioning for stable tags: patch for compatible fixes, minor for
compatible features, and major for breaking changes.
