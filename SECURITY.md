# Security policy

Report suspected vulnerabilities through the repository host's private
security reporting feature or a maintainer's published private contact. If
neither is available, open an issue titled “Private security report request”
with no vulnerability details and ask maintainers for a private channel.
Include affected versions, impact, and reproduction steps only in that private
channel; never post secrets or exploit details publicly.

Maintainers should acknowledge reports, coordinate a fix and disclosure with
the reporter, and publish an advisory when appropriate. Do not promise a
response time unless the project can meet it.

Security fixes should identify affected versions and the first fixed version.
Publish package updates through the release and changelog process in
`CHANGELOG.md`.
